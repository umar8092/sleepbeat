# Heartbeat Generator

Plays a heartbeat sound at 183 BPM using the Web Audio API. Click start to hear it.

**Live demo:** https://umar8092.github.io/heartbeat-generator/

## Use it

Download or clone the repo and open `index.html` in a browser. No build step or dependencies.

```
git clone https://github.com/umar8092/heartbeat-generator.git
```
